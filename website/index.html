Meet the memory model ↗
Facts What happened. What was observed.+
facts → factual
“The Atlas project uses PostgreSQL.”

Concrete information from a source or an interaction. A factual label describes the memory’s role; it does not certify that the statement is true.

write_fact()Illustrative note
Preferences How someone wants things done.+
preferences → preference
“I prefer a short summary before the technical detail.”

Preferences, feedback and corrections give an agent context about a person. Earlier and later statements can coexist; a newer preference is not automatically a universal replacement.

write_preference()Illustrative note
Insights What to carry into the next task.+
insights → procedural_anchor
“Check whether port 5432 is free before starting the database.”

A transferable lesson or procedure. In the engine, an insight is a procedural anchor: a note that can guide a future action. It is retrieved context, not executable code.

The optional agent pipelineThree LLM stages around deterministic retrieval
  1. Information-Need Agent

    What do we need?

    Identify the facts, preferences or procedures this task depends on.

    An information need
  2. Retrieval Planner Agent

    Where should we look?

    Rewrite the need into a query. Keyword rules select the relevant drawers.

    A query + selected stores
  3. TESSERA engine

    Find the evidence.

    Retrieve and rank notes. Keep the raw candidates available.

    Retrieved memories
  4. State Inference Agent

    Bring the clues together.

    Generate a context summary for the consuming agent to inspect and use.

    Assisted context + raw memories

These “agents” are prompt-based calls to an application-supplied llm_fn. The generated summary is derived text, with no machine-checked grounding guarantee. Explore the pipeline and its boundaries ↗

View the Python query +

With the two example notes in ./memories:

from tessera import TesseraEngine

engine = TesseraEngine(storage_dir="./memories")
engine.build_index()

results = engine.retrieve_context(
    "When is the Atlas launch?",
    top_n=2,
)

for result in results:
    print(result["relevant_evidence"])
    print(result["provenance"])
