# Historical TESSERA demonstration

`tessera-apresentacao.html` retains the original 22-slide HTML structure with
project-neutral narrative references and the repository's canonical TESSERA
artwork. It uses local assets and needs no build step.

This is a historical presentation, not the current product contract. Consult
[the documentation map](../README.md) and [QUMem fidelity audit](../QUMEM-GAP-ANALYSIS.md)
for current behavior and experimental limits. The original private-project
branding and artwork remain in [pinned Git history](https://github.com/LuigiFerronatto/TESSERA/tree/20814a47ec0f72d7bea0639e0b057df1ecf5cded/docs/slides),
rather than the current public asset tree.

## View

Open the HTML file in a browser. Scroll or use the existing arrow/PageUp/PageDown
navigation. The slide count stays 22. Local Carbona font files are unchanged;
this cleanup makes no new license or authorship claim for retained assets.
